# Common Bugs Checklist

コードレビュー時に注意すべき、言語別のバグ・問題チェックリスト。

## 共通の問題

### ロジックエラー
- [ ] ループや配列アクセスの off-by-one エラー
- [ ] 論理式の誤り（ド・モルガンの法則違反など）
- [ ] null / undefined チェック漏れ
- [ ] 並行処理での競合状態（race condition）
- [ ] 比較演算子の誤り（== vs ===、= vs ==）
- [ ] 整数のオーバーフロー / アンダーフロー
- [ ] 浮動小数点比較の問題

### リソース管理
- [ ] メモリリーク（接続・リスナー未解放）
- [ ] ファイルハンドル未クローズ
- [ ] DB接続未解放
- [ ] イベントリスナー未削除
- [ ] タイマー / interval 未クリア

### 例外処理
- [ ] 例外を握りつぶしている（空の catch）
- [ ] 汎用例外で具体的な原因が隠れている
- [ ] エラー伝播漏れ
- [ ] 不適切な例外型
- [ ] finally / cleanup 処理漏れ


## SQL

### セキュリティ

- [ ] SQLインジェクションの脆弱性（文字列連結によるクエリ構築）
- [ ] プリペアドステートメント（プレースホルダー）の利用漏れ


### パフォーマンス

- [ ] インデックス不足
- [ ] SELECT * の使用
- [ ] N+1 クエリ
- [ ] LIMITなし

---

## API設計

### REST

- [ ] リソース名が一貫している
- [ ] HTTPメソッドが適切
- [ ] ステータスコードが正しい
- [ ] ページネーションがある

### バリデーション

- [ ] 入力検証がある
- [ ] 型チェックがある
- [ ] 範囲チェックがある
- [ ] サニタイズされている

---

## テスト

### 品質

- [ ] 実装ではなく振る舞いをテストしている
- [ ] エッジケースがある
- [ ] flaky（不安定）でない
- [ ] 外部依存を分離している
- [ ] 異常系テストがある
